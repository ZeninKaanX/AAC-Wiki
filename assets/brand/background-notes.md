# AtlasOyuncu background

Official background URL: https://atlasoyuncu.com/assets/core/images/uploads/b13dcc1691be37eab05ff679a69cb11d.gif

The main AtlasOyuncu site uses this Minecraft underwater scene in its header. It was downloaded for the user-requested matching theme, inspected and converted locally into `atlas-background.webp` (static fallback) and `atlas-background.mp4` (silent H.264 loop). Original source: 800×450, about 2.51 seconds. No image generation was used for the current background.

The animated version loads on desktop home only and pauses when the page is hidden or motion is turned off. Mobile, reduced-motion and data-saving modes use the static image.
